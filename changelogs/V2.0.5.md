# 枫林月语整合包 v2.0.3 更新日志

- **发布日期**：2026-02-10
- **Minecraft 版本**：1.21.1
- **Loader**：Fabric
- **客户端更新类型**：玩法更新
- **更新标签**：update-log

## 本次主要更新亮点

1. **新增游戏个人信息后台**
   - 访问地址：[Akiyy Hub](http://mchub.akiyy.top:3000/)
   - 后台功能：
     - 编辑服务器内个人昵称（不会修改原游戏名）
     - 编辑个人皮肤，支持以下方式：
       1. 正版用户通过输入用户名拉取皮肤
       2. 通过 Ely.by 皮肤站拉取个人皮肤
       3. 通过上传皮肤图片 URL 拉取皮肤
       4. 在后台直接上传皮肤图片定义皮肤
   - 后续功能待开发

2. **新增权限组**
   - 新增游戏内权限组，减少服务器管理精力消耗
   - 当前权限组：
     - Admin
     - Developer（拥有部分 Carpet 等 Mod 的高级指令权限）
     - Member（拥有普通玩家常用指令权限）

3. **新增实用指令**

   1. **传送相关指令**
      - `/tpa <player>` → 向指定玩家发送传送请求（传送到对方位置）
      - `/tpahere <player>` → 向指定玩家发送传送请求（让对方传送到你这里）
      - `/tpaccept <id>` → 接受传送请求（通常可直接点击消息中的接受链接）
      - `/tpdeny <id>` → 拒绝传送请求（通常可直接点击消息中的拒绝链接）

   2. **家园相关指令**
      - `/home [home]` → 传送到默认家或指定家
      - `/sethome <name>` → 添加一个新家（受权限组限制）
      - `/delhome [home]` → 删除默认家或指定家
      - `/listhomes` → 列出你所有的家

   3. **其他实用指令**
      - `/back` → 传送到你最后使用任何传送命令的位置（包括原版指令）
      - `/rtp` → 将你传送到世界上一个随机位置
